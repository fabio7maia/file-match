Elyvan FileMatch

Renomeie vários ficheiros de uma só vez a partir de uma lista Excel ou CSV.

1. Escolha os ficheiros

2. Escolha a lista (Excel ou CSV)

Primeira coluna: referência (nome do ficheiro sem extensão). Segunda coluna: novo nome. Pode incluir cabeçalhos "Referência" e "Novo nome".

3. Confirme a pré-visualização

    Escolha ficheiros e uma lista para ver a pré-visualização.

    Ficheiro original Referência Novo nome Estado Mensagem

    4. Descarregue o ZIP

    Os originais não são alterados: o ZIP contém apenas cópias renomeadas dos ficheiros prontos.

    Funciona localmente no navegador: os ficheiros não são enviados para nenhum servidor. Compra única de referência: 5 €, sem subscrição.
